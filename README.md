# ✈️ Airline Passenger Satisfaction - Power BI Data Analysis

## 📌 Project Overview
This project analyzes airline passenger data to uncover the key drivers of customer satisfaction. By evaluating over 129,000 passenger records, this interactive Power BI dashboard identifies which services (e.g., seat comfort, in-flight Wi-Fi, online boarding) impact satisfaction the most, and highlights the differences between travel classes and customer types.

## 🛠️ Tools & Technologies
*   **Data Visualization & Analytics:** Power BI
*   **Data Sources:** CSV Files (`airline_passenger_satisfaction.csv`, `data_dictionary.csv`)
*   **Data Processing:** Power Query

## 📊 Dashboards & Key Insights

### 1. Demographics & General Satisfaction
This dashboard provides a high-level overview of the passengers and their overall satisfaction rates.

![Service Quality](Dashboard%20Images/Screenshot%202026-09-25%20053839.png)

**Key Metrics:**
*   **Total Passengers:** 129,880
*   **Average Satisfaction Rate:** 43.45% (Significant room for improvement to reach the 80.00% target).
*   **Average Age:** 39 years
*   **Average Flight Distance:** 1,190 Miles

**Key Insights:**
*   **Travel Class:** Business class passengers show a significantly higher satisfaction rate compared to Economy class passengers.
*   **Travel Type:** Passengers traveling for Business are generally more satisfied than those traveling for Personal reasons.
*   **Customer Loyalty:** Returning customers form the bulk of the passenger base, but a large portion remains neutral or dissatisfied.
